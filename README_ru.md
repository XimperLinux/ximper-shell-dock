# ximper-shell-dock

![Демонстрация дока](assets/dock-demo.gif)

Панель Dock — компонент Ximper Shell.

Док для Wayland с индикаторами приложений, автоскрытием, плавающим и закреплённым режимами, папками-стопками в стиле macOS, увеличением иконок при наведении, анимацией запуска и перетаскиванием. Написан на Vala с GTK4, libadwaita и gtk4-layer-shell.

Поддерживает Hyprland и Niri через вспомогательные модули композитора.

## Возможности

- Плавающий и закреплённый режимы; для плавающего режима доступно автоскрытие.
- Индикаторы запущенных и активных приложений; незакреплённые запущенные приложения выводятся отдельно.
- Волна увеличения иконок при наведении с настраиваемыми масштабом, радиусом и скоростью реакции; нажатия и перетаскивание работают и на увеличенной части иконки.
- Необязательная анимация подпрыгивания иконки до появления окна запущенного приложения.
- Ширина дока адаптируется к монитору: размер иконок уменьшается, только если настроенный размер не помещается.
- Перестановка иконок приложений и папок-стопок перетаскиванием; приложение можно перетащить из меню плиток, чтобы закрепить его. Анимированный промежуток при перестановке сохраняет стабильное положение элементов.
- Добавление папок в виде стопок перетаскиванием каталога из файлового менеджера на док или через его контекстное меню. Содержимое стопки открывается в отдельной layer-shell поверхности в виде прокручиваемой сетки или списка; для файлов используются системные миниатюры, а элементы можно перетаскивать в другие приложения.
- Необязательная корзина в конце дока: открывается по щелчку, принимает файлы для перемещения в корзину и позволяет очистить её из контекстного меню. Значок показывает, есть ли в корзине файлы.
- Содержимое дока синхронизируется на всех мониторах сразу после добавления, удаления или перестановки приложений и папок-стопок.

## Сборка

```sh
meson setup _build
ninja -C _build
./_build/src/ximper-shell-dock
```

## CLI

```sh
ximper-shell-dock --pin <desktop_id>
ximper-shell-dock --unpin <desktop_id>
```

## Поддержка композиторов

Док отслеживает запущенные и активные окна с помощью модулей для конкретных композиторов:

- Hyprland: событийный сокет (`.socket2.sock`) и `hyprctl` для получения состояния, фокусировки и закрытия окон.
- Niri: `niri msg --json windows` и `event-stream`; для фокусировки и закрытия используются идентификаторы окон Niri.

## Конфигурация

`~/.config/ximper-shell/dock/config.json`

```json
{
  "mode": "floating",
  "autohide": false,
  "show_trash": false,
  "magnify_on_hover": false,
  "bounce_on_launch": false,
  "bounce_duration": 200,
  "magnify_scale": 135,
  "magnify_radius": 2.0,
  "magnify_animation_duration": 120,
  "icon_size": 48,
  "layer": "top",
  "launcher_fallback": "wofi --show drun",
  "pinned_apps": ["org.gnome.Nautilus.desktop"],
  "dock_items": ["app:org.gnome.Nautilus.desktop"],
  "dock_folders": [{
    "path": "/home/user/Documents",
    "display": "stack",
    "view": "grid",
    "sort": "name"
  }]
}
```

| Ключ | Тип | По умолчанию | Описание |
|-----|-----|-------------|----------|
| `mode` | string | `"floating"` | `"floating"` или `"pinned"` |
| `autohide` | bool | `false` | Скрывать док, когда он не используется; работает только в режиме `"floating"` |
| `show_trash` | bool | `false` | Показывать системную корзину после папок-стопок в конце дока |
| `magnify_on_hover` | bool | `false` | Включить волну увеличения иконок при наведении |
| `magnify_scale` | int | `135` | Максимальный размер иконки при наведении, в процентах |
| `magnify_radius` | float | `2.0` | Радиус волны в ширинах иконки с каждой стороны |
| `magnify_animation_duration` | int | `120` | Время реакции волны в миллисекундах |
| `bounce_on_launch` | bool | `false` | Подпрыгивание иконки при запуске приложения |
| `bounce_duration` | int | `200` | Длительность подъёма в анимации подпрыгивания, в миллисекундах |
| `icon_size` | int | `48` | Размер иконок дока в пикселях |
| `layer` | string | `"top"` | Слой layer-shell: `"background"`, `"bottom"`, `"top"` или `"overlay"`. Числовые значения из старых конфигураций автоматически переносятся при сохранении. |
| `launcher_fallback` | string | `"wofi --show drun"` | Команда, запускаемая, когда меню плиток недоступно |
| `pinned_apps` | string[] | | Совместимое представление закреплённых приложений с идентификаторами desktop-файлов; синхронизируется с `dock_items` |
| `dock_items` | string[] | | Упорядоченные записи приложений в формате `app:<desktop-id>` |
| `dock_folders` | object[] | | Папки-стопки; см. ниже |

### Пользовательский CSS

Создайте `~/.config/ximper-shell/dock/style.css`, чтобы изменить внешний вид дока без редактирования установленных файлов. Эта таблица стилей загружается с пользовательским приоритетом и перекрывает правила из поставляемой таблицы. После изменения перезапустите Dock.

Полный перечень доступных правил и хорошая основа для собственного файла — поставляемая таблица [`data/ximper-shell-dock.css`](data/ximper-shell-dock.css). В установленной системе она обычно находится по пути `/etc/xdg/ximper-shell/dock/style.css`.

```sh
mkdir -p ~/.config/ximper-shell/dock
cp /etc/xdg/ximper-shell/dock/style.css \
  ~/.config/ximper-shell/dock/style.css
```

Например, чтобы настроить фон дока и тень в плавающем режиме:

```css
.dock-content {
  background: @window_bg_color;
}

.dock-window.floating .dock-content {
  box-shadow: 0 1px 3px @headerbar_shade_color;
}
```

Полезные селекторы: `.dock-window`, `.dock-window.floating`, `.dock-window.pinned`, `.dock-content`, `.dock-icon`, `.dock-indicator` и `.dock-folder-item`. Цвета тем GTK/libadwaita, например `@window_bg_color`, `@headerbar_bg_color` и `@accent_bg_color`, следуют за активной системной темой.

### Параметры папок-стопок

Каждая запись `dock_folders` содержит абсолютный `path` и необязательные параметры представления:

| Ключ | Значения | По умолчанию | Описание |
|-----|----------|-------------|----------|
| `display` | `"folder"`, `"stack"` | `"stack"` | Вид значка папки в доке |
| `view` | `"grid"`, `"list"` | `"grid"` | Раскладка при открытии папки |
| `sort` | `"name"`, `"modified"`, `"kind"` | `"name"` | Порядок элементов |
| `columns` | `1`–`12` | `4` | Число столбцов в сетке |
| `rows` | `1`–`10` | `3` | Число видимых строк до прокрутки |
| `item_size` | `32`–`128` | `56` | Размер значков элементов в пикселях |
| `favorites` | `string[]` | `[]` | URI избранных элементов; они показываются вверху |

Через контекстное меню папки можно изменить эти параметры или удалить стопку. Щёлкните правой кнопкой по элементу внутри открытой папки, чтобы добавить его в избранное; избранное всегда выводится первым. Папки выводятся в отдельной секции с правой стороны дока. Чтобы добавить каталог сразу после существующей стопки, перетащите его на эту стопку.

### Корзина

Включите `show_trash` в окне настроек или файле конфигурации, чтобы добавить системную корзину в конец дока. Щелчок открывает `trash:///`; перетащите файл на значок, чтобы переместить его в корзину. Контекстное меню содержит пункт **Очистить корзину…** с подтверждением перед безвозвратным удалением её содержимого.
